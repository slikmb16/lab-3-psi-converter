## ✨ Возможности

- 🔄 Конвертация между всеми валютами из официального XML Национального банка Молдовы (BNM).
- 🧮 Точный расчёт через MDL с учётом `Nominal` — работает в обоих направлениях.
- 📅 Поиск актуального рабочего дня, понятное отображение даты и источника курса.
- 💾 Локальный JSON-кэш: последний успешный курс доступен после перезапуска и при временном отсутствии сети.
- ⚡ Быстрые суммы, смена валют местами, копирование результата и история шести последних операций.
- 📊 Отдельный каталог курсов с поиском, сортировкой и избранными валютами.
- 🏦 Каталог банков: адреса, телефоны, e-mail, ссылки на официальный сайт и карту.
- 🧭 Финансовый гид по безопасному обмену и переводам.
- 🧪 Встроенная страница с 10 интерактивными проверками: каждую можно запустить отдельно или все вместе.

## 🚀 Запуск приложения

Нужен только **Python 3.10+**. Устанавливать библиотеки не требуется.

```powershell
python -m currency_converter
```

После запуска терминал напечатает адрес, например:

```text
Веб-приложение запущено: http://127.0.0.1:8000
```

Откройте **именно тот базовый адрес, который напечатал терминал**. Он всегда будет одним из свободных локальных портов `8000`–`8009`. Если `8000` занят, приложение само выберет следующий свободный порт — ничего менять в коде не нужно.

Ниже — готовые ссылки для стандартного случая, когда в терминале указан порт `8000`:

Чтобы остановить приложение, вернитесь в окно терминала и нажмите `Ctrl+C`.

### Если браузер показывает `ERR_EMPTY_RESPONSE`

Обычно это означает, что открыта вкладка от старого остановленного сервера. Запустите команду ещё раз и откройте свежий адрес из терминала. Не нужно перезагружать старую вкладку с прежним портом.

## 🧪 Проверка качества

Запуск серверных unit-тестов:

```powershell
python -m unittest discover -s tests -v
```

Проверяются XML-разбор BNM, номиналы, ошибки входных данных, обе стороны конвертации, одинаковые валюты, рабочие дни, кэш и все HTTP-страницы. В текущей версии проходят **16 тестов**.

Для клиентской части откройте [страницу тестов](http://127.0.0.1:8000/tests.html): там доступны десять сценариев по одному и кнопка общего запуска.

## 🏗️ Устройство проекта

```text
currency_converter/
├── bnm.py          # XML BNM и сетевой клиент
├── cache.py        # постоянный JSON-кэш
├── models.py       # снимок курсов и формула Decimal
├── service.py      # валидация и поиск актуальной даты
├── web.py          # локальный HTTP-сервер и API
└── web_static/     # HTML, CSS и JavaScript интерфейса
tests/              # серверные unit-тесты
specs/              # SDD: спецификация, план, задачи и чек-лист
REPORT.md           # отчёт по лабораторной
```

## 📡 Курсы и кэш

Источник данных — официальный XML-эндпоинт BNM:

```text
https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY
```

Последний корректный снимок сохраняется в `%LOCALAPPDATA%\PSI-Lab3-CurrencyConverter\rates.json`, поэтому не теряется после закрытия приложения.
