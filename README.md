## ✨ Что умеет приложение

- 🔄 Конвертирует любую пару валют из официального XML Национального банка Молдовы (BNM).
- 🧮 Считает через MDL с учётом поля `Nominal` — корректно и в прямом, и в обратном направлении.
- 📅 Показывает источник и реальную дату курса; ищет ближайший рабочий день, если сегодня данных нет.
- 📡 Не падает без интернета: предлагает использовать последний сохранённый курс.
- 💾 Сохраняет курс локально и использует его после перезапуска.
- ⚡ Поддерживает быстрые суммы, обмен валют местами и копирование результата.
- 🕘 Хранит последние шесть расчётов прямо в браузере.
- 📊 Имеет отдельную страницу **«Курсы»**: полный справочник, поиск, сортировка и избранные валюты.
- 🧪 Имеет интерактивную страницу с 10 отдельными JavaScript-проверками и общим запуском.

## 🚀 Быстрый старт

Нужен только Python 3.10 или новее — никаких пакетов устанавливать не нужно.

```powershell
python -m currency_converter
```

Откройте в браузере [http://127.0.0.1:8000](http://127.0.0.1:8000). Если порт 8000 уже занят, приложение автоматически выберет 8001 и напишет точный адрес в терминале. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

| Страница | Адрес | Назначение |
|---|---|---|
| Конвертер | `http://127.0.0.1:8000/` | Расчёт суммы и история операций |
| Курсы | `http://127.0.0.1:8000/rates.html` | Поиск, сортировка и избранные курсы |
| Тесты | `http://127.0.0.1:8000/tests.html` | Запуск клиентских сценариев |

## 🧪 Проверка качества

Серверные unit-тесты запускаются одной командой:

```powershell
python -m unittest discover -s tests -v
```

Покрыты XML-разбор, номинал, пустой и некорректный ответ, расчёт в обе стороны, одинаковые валюты, валидация, fallback по рабочим дням, кэш и HTTP-страницы. В браузере на странице «Тесты» можно запускать сценарии по одному или все сразу.

## 🏗️ Устройство проекта

```text
currency_converter/
├── bnm.py          # XML BNM и сетевой клиент
├── cache.py        # постоянный JSON-кэш
├── models.py       # снимок курсов и формула Decimal
├── service.py      # валидация и поиск актуальной даты
├── web.py          # локальный HTTP-сервер и API
└── web_static/     # интерфейс HTML / CSS / JavaScript
tests/              # unit-тесты
specs/              # SDD-спецификация, план, задачи и чек-лист
REPORT.md           # обязательный отчёт
```

## 📡 Источник данных и кэш

Используется официальный XML-эндпоинт BNM:

```text
https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY
```

Последний корректный снимок курсов хранится в `%LOCALAPPDATA%\PSI-Lab3-CurrencyConverter\rates.json`. Он не удаляется при перезапуске приложения.
