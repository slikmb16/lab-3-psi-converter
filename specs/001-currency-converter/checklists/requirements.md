# Чек-лист качества требований

- [x] Требования описывают поведение, а не ненужные детали реализации.
- [x] Для каждого обязательного поведения есть сценарий приёмки.
- [x] Учтены ошибочный ввод, отсутствие сети, отсутствие курсов и одинаковые валюты.
- [x] Источник и смысл его курсов явно определены.
- [x] Есть проверяемые нефункциональные ограничения.
- [x] Ограничение области работ предотвращает лишние функции.
