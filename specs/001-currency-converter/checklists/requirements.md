# Requirements Quality Checklist

- [x] Requirements avoid implementation details where behaviour is the goal.
- [x] Each required behaviour in the assignment has an acceptance scenario.
- [x] Edge cases cover malformed input, no network, no rates and equal currencies.
- [x] Data source and its rate semantics are explicitly defined.
- [x] Testable non-functional constraints are present.
- [x] Scope exclusions prevent feature creep.
